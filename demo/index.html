Veilo — independent auction audit

Check an auction result without trusting the seller.

Ten shielded outputs were published: five sealed bids and five decoys belonging to other addresses. This page decrypts all ten with the seller's public viewing key and recomputes the winner and the clearing price — the price the winner actually pays — in your browser.

That key is the most the seller ever holds, and it still does not reveal an amount: each memo carries a 32-byte commitment to a bid, which cannot be opened without the bidder's own reveal.

What this is and is not

The ciphertexts below come from Zcash's real Sapling note encryption (sapling_crypto) and carry real 512-byte Veilo envelopes, so the decryption above is genuine — there is no mock anywhere. These ten outputs were generated locally and were not mined. This demonstrates the cryptography and the auction arithmetic, not transaction broadcast. Broadcast is proved separately: demo/chain-probe/ holds a different transaction that zcashd 6.20.0 mined into regtest block 111 with a packed Veilo bid in its memo. The viewing key shown with the result is a deterministic test value, which is why it looks like a placeholder.
