Veilo — independent auction audit

Recompute a sealed-bid auction's clearing price from chain ciphertexts, in your browser, using nothing but the seller's public viewing key. That key can read the escrow but cannot spend from it, so the seller never had the ability to see a single bid.

What this is and is not

The ciphertexts below come from Zcash's real Sapling note encryption (sapling_crypto) and carry real 512-byte Veilo envelopes, so the decryption above is genuine — there is no mock anywhere. They were not mined on a chain. This demonstrates the cryptography and the auction arithmetic, not transaction broadcast; that is a separate claim, currently blocked on a Zallet/zebra state-format gap.
